## 里程碑任务卡

### UX-00 回归与追溯基线

- 依赖：既有生产包；输入：旧 roadmap、最新实际源码、B1—B4 反例。
- 执行：独立目录重跑契约、对抗、审计、场景、决策、e2e、freshness、resilience、紧凑和宽屏 UI、业务保存更正重启、来源 resync、三阶段反例；检查包准入。
- 完成条件：阻断项已修或证明与后续修改无关；保存旧三份文档及哈希。不能用旧报告替代新运行。
- 交接：baseline/report.json 每套结果，失败精确日志和修复范围。

### UX-01 经历结果和本地决定仓库

- 依赖：UX-00；实施文件：新增 `src/47_experience.splash`，导出器。
- 执行：单独 experiences 文件，不复用主体 Flow；临时回顾保存才进入目录，新建保留草稿；记录身份含 app/module/id，决定绑定 experience；成员排除、恢复与费用确认分离。
- 决定带观察修订；修订变化要求重新确认，源删除不能靠恢复排除复活；继承既有全局排除而不搬迁/覆盖旧文件。
- 完成条件：跨来源同号、经历隔离、修订失效、重启持久化；业务存储不产生新记录。
- 交接：仓库 schema、实际隔离 app 文件、对应测试结果。

### UX-02 经历首页与原业务入口

- 依赖：UX-01；实施文件：`src/65_experience_ui.splash`、60_ui、构建器。
- 执行：经历目录、搜索、新建；中心日期组、原文来源、费用口径；详情与返回；设置集中来源/导入说明/云端规划；我的空间保留既有日历账本经期。
- 日期组只表示同日记录，不暗示因果或模型生成关系；无数据提供真实空状态。导入样本始终披露。
- 完成条件：真实生产 Splash 在 412 和 1280 宽度可操作，两故事、详情、恢复、旧业务可达；截图审查。
- 交接：控件 ID、导航变化与旧回归适配说明。

### UX-03 真实 Agent 计划进入经历界面

- 依赖：UX-01/02；实施文件：47_experience、现有 model.complete 接口。
- 执行：新输入框返回固定结构计划，选择目录主题、日期及最少来源；程序校验白名单与日期，实际读取导入投影并展示真实记录。保留问题，澄清沿用上下文。
- 本次任务绑定 request/experience/query revision；取消及切换后丢弃旧回调；没有物理取消 API 时如实说明。读取失败不清空上次合法结果；不伪造工具过程。任务记录只存范围、状态、计数和时间。
- 完成条件：真实 Provider 两问题选不同主题并呈现；无模型、非法计划、取消迟到不污染；无写源副作用。
- 交接：模型路径、输入输出 schema、真实回执及生产包摘要。

### UX-04 来源变化和用户核验

- 依赖：UX-01/02/03；实施文件：47、65 和受控测试。
- 执行：重新读取已导入数据，不称实时拉取；显示新增、更正、移除；来源关闭立即清理详情和任务上下文；已排除列表可恢复；费用逐条确认后按币种程序统计，未确认金额单列。
- 费用确认仅表示该记录计入本经历，不冒充具体事件间的关系确认；复杂多事件候选边见 UX-07。
- 完成条件：真实来源更正/删除→正式 sync→UI 读回；重复读取幂等；关闭来源后正文/金额不泄露；恢复权限选择不会伪装宿主重新授权。
- 交接：点击操作、源修订、读回截图、零业务写入证据。

### UX-05 集成回归和交接

- 依赖：UX-01—04；执行：重建、stamp/check；新 UI 端到端、旧业务回归、真实模型；保护文件核对。
- 完成条件：不能仅以 hub check 或静态测试通过代替界面；每个未达标项写明。更新产品实现表、演示步骤、任务账本和根 agent.md。
- 交接：源和包摘要、已完成清单、限制、下一命令。发布包刷新/外发仍走旧 DF-21/22/25，不覆盖冻结旧包。
