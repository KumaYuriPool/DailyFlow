## 必须保留的约束

- 产品名 DailyFlow，以日历为入口，事件、时间、关联、Flow、操作入口构成公共数据协议。Flow 可以跨模块组织，同一事件属于多个 Flow 不应复制业务记录或重复计入金额。
- **只使用 OctoScript/Splash 应用代码**。可以使用已公开、获授权且验证可用的宿主 API；不能新增或修改 Shell、Makepad、host service、其他 Rust 层，也不能添加原生后台服务绕过限制。Python/PowerShell 可用于开发、启动、测试和证据整理，不得替代应用的生产业务或持久化逻辑。
- “明确内容自动记，含糊再问”。计划和别人的消费不自动记成本人支出。保存成功才显示成功；模型不可用时保留输入并提供手工路径。
- 经期模块主动开启，仅记录实际情况，不做预测。区间结束未知时不制造事实。
- 默认采用路线图的保守删除规则：删除 Flow 仅移除组、关联与专属规则，保留源记录及其他 Flow 引用；删除原始记录走模块业务操作。
- AppCard 是宿主对话交互卡片路径，glance 是 Shell 独立信息面板卡片路径；不是第一次卡片和后续反馈的顺序。应用内部固定卡片可先做，不能把它宣称为已接通 AppCard/glance。

## MVP 开发范围

以路线图 M0–M4 为目标，建议分步做成闭环，每步通过后继续：

1. **协议与真实日历**：设计有版本的数据格式；支持真实年月、大小月、闰年、星期偏移、日期选择、跨月跨年。时间区分事件日期、创建时间、计划到期时间与实际完成时间。
2. **Flow 与内部路由**：创建、查看、关联、过滤、隐藏或删除 Flow；日历与时间线可以进入同一模块记录；更正后同步更新。
3. **专业记录**：记账、经期和通用任务的最小 CRUD；金额精确计算；重复记录检测；任务完成与延期；持久保存和重启读回。日记完整模块可后置，不阻塞这版。
4. **新闻 Flow 样例**：支持人工导入带来源、时间的材料或事件；验证多个进展组成时间线、重复处理和来源回看，不要求自动抓取所有新闻。
5. **对话与固定操作卡片**：尽早做真实 model.complete 能力实验。若目标宿主现有接口可用，打通结构化解析、业务校验、保存回执、更正和撤销；不能用关键词解析或预设结果冒充真实模型。若接口、提供方或授权缺失，留下具体证据并实现完整手工路径和可恢复的失败状态，继续其他工作；最终明确该验收项未完成。
6. **规则与提醒**：每次账目变动检查预算，首次越过阈值提醒并去重；任务运行时到期提醒和重开后补偿，支持完成、延期、取消。不能承诺 App 关闭或设备休眠后准时唤醒，除非已有宿主接口经过单独实测。
7. **连续使用准备**：可直接启动的 Windows 运行脚本、空状态、输入校验、敏感内容显示控制、基础导出和恢复验证、操作说明与实际验收报告。

界面采用简洁可读的日历和详情布局，优先完成真实业务闭环。避免在一个视图内堆叠全部页面；在已验证的 Splash 能力范围内选择合理实现。技术选择由开发 Agent 自主完成，不必为每个字段或布局反复询问。

## 必须实际跑过的验收

- 准入检查、启动日志、截图、真实控件树、实际点击输入、文件状态和重启读回均需证据；零错误日志和 gate PASSED 单独都不能判定完成。
- 同一账目出现在两个 Flow 时只计一次；更正金额后列表、日历摘要、卡片和预算一致。
- 删除 Flow 后源记录和其他组仍在；删除源记录后相关展示与提醒失效。
- 经期开始重复输入不制造两个周期；未开启模块不自动写入。
- 预算越限只提醒一次；任务延期后旧提醒不再触发；重启补发不会重复。
- 日历覆盖跨年、闰年二月和不同星期偏移；用户输入日期不固定在样例月。
- 新闻节点能打开或显示来源，重复导入不重复创建同一进展。
- 模型失败、含糊输入和保存失败不能显示虚假成功；真实 AI 未跑通必须单列未完成。
- 备份恢复后的记录、Flow 关联、任务和合计一致。测试数据与真实数据隔离。
- 测试结束关闭本轮启动的进程，验证端口释放；不要关闭其他用户进程。

连续 7 天个人试用需要真实时间与使用反馈，本轮只能交付可试用程序及测试证据，不得模拟或宣称已完成 7 天试用。不要为了等待该周期阻塞本轮实现，也不要擅自创建自动化。
