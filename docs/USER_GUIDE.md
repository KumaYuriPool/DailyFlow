# DailyFlow Windows 试用说明

双击项目根目录 `run-dailyflow.cmd`，或在 PowerShell 运行：

```powershell
& 'D:\Life\AgenticApp\DailyFlow\run-dailyflow.ps1'
```

脚本使用工作区已经验证的 Python、hub 和 card-host。默认端口 8171，被占用时不会结束原进程。关闭窗口退出。正常数据位于项目 `.local-state/dailyflow/`；本轮验收使用 `build/mvp-acceptance/dailyflow/`，不会混入个人数据。请勿对同一数据目录同时开启多个实例。

## 日常操作

1. **日历**：上月、下月、今天，或输入 `YYYY-MM-DD` 跳转；点击日期。年月、星期偏移和闰年由程序计算。
2. **Flow**：输入名称创建。选中 Flow 后可改名、显示/隐藏、删除或导入新闻。选中一个 Flow 再回日历可按组查看；“查看全部记录”清除组过滤。
3. **记录**：点击记账、任务、经期或新闻的新建按钮。填写日期和业务信息后保存。点击列表条目打开同一条详情，可以更正或删除。在详情点击 Flow 名称加入/移除关联。
4. **经期**：先到设置主动开启，再选择是否显示敏感记录。开始日为实际日期，结束未知时留空。同日或重叠输入不会产生第二个周期；应回原记录修改。
5. **任务**：填写到期日期和 `HH:MM`，按北京时间处理。详情可完成、延期一天、取消、重新待办；也可直接改日期时间后保存。完成会记录实际完成时间。
6. **新闻**：先创建主题 Flow，再人工输入事件标题、发生日期、文章地址或出版出处。详情显示来源。验收中的“人工验收材料 A”仅是测试材料，不代表真实新闻。
7. **预算与提醒**：设置月预算（0 关闭）。首次超预算提醒在“提醒”页查看；账目跨组只计算一次。应用运行中每 20 秒检查任务，重开补偿错过的任务，已读不会重新刷出。
8. **对话**：当前 Windows card-host 没有 model 服务，实际调用会显示错误并保留输入。可以直接使用手工卡片。当前没有可用的 AI 自动记账、歧义追问闭环、AppCard/glance 或关闭应用后的后台通知。

## 备份、恢复、旧数据

设置 → 导出备份，会在当前数据目录生成 `backup.json`。将该文件复制到安全位置即可留存；应用不会上传。恢复时把需要的备份放回同一数据目录，点击两次“恢复 backup.json”。恢复会替换当前数据，并保存 `before-restore.json`。恢复后检查记录数、Flow 与金额。

首次启动不会自动覆盖或迁移旧账本。设置 → 导入旧 expenses.json 会读取旧文件，重复导入按旧 ID 去重。本轮开发前的源码和旧数据副本在 `build/mvp-baseline-20261002/`。

显示隐藏只影响页面可见性，磁盘备份仍包含原始敏感记录。日期范围为 1970–2100，金额最多两位小数；本版不支持多币种、经期预测、多设备同步和多实例并发写入。

## 试用范围

这是可手工连续使用的单 App 验证版，不是已经完成 AI 的完整愿景。连续 7 天个人试用尚未发生。试用时记录误保存、重复记录、找回困难、提醒漏发及恢复问题；不要将关闭应用后的无提醒视为已支持后台调度。
