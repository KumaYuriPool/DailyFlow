# DailyFlow 0.5.1 使用说明

## 打开与记录

双击 `run-dailyflow-ai.cmd` 使用现有 OctoSense 桌面和 Provider。启动进入对话，底部输入常驻；左栏可打开日历、账本、全部入口或数据管理。顶部 Flow 按钮可搜索并选择事件；“说件新事”清空当前输入与回执，恢复今天和全部事件语境。

例如依次输入：“今天给团子洗护花了120元”“给团子买护理用品花了35元”“10月11日15点再带团子去护理”“刚才洗护费不是120，是110”“这次护理花了多少”。无需先建 Flow 或档案。明确事实保存后就地显示回执；金额或归属不明确时先问。计划不会增加支出。

明确日期优先，“昨天”等相对日期以实际今天计算；没有日期则采用输入区显示的日期。取消或在等待时改写输入，会使旧模型回复失效。新内容不会自动继承上次事件，除非明确关联。

## 回看与更正

点击日历的视图下拉按钮，搜索“普通日历／来源：日历”或“账本日历／来源：记账”。切换保留年月、选中日和“全部/此事件”范围。选中日下方显示事项或支出，日格无金额不代表确认零消费。没有 Flow 的支出也正常显示。工作区采用整页分层展示，可“回到对话”。

点日期、定位、切月份只是浏览，不改变输入语境。点“以这一天补记”才使用该日记录，并回到对话；输入区显示补记日期与事件范围。普通导航保留草稿；切换 Flow 会清除旧追问并取消未完成的模型请求，草稿文字保留。补记日期和会话不跨重启。

从事项或费用进入事件图。实线状态为已发生，虚线状态为计划，费用节点标明归属；后续安排标明关联的具体事项编号。点击节点先查看，再点“修改”。更正金额或日期更新同一个源记录；“定位到日历”查看实际记账日期。返回恢复来源与滚动位置。

“移出”仅解除归属。“删除源记录”需要再次点击确认；删除费用保留事项。“删除事件关系”同样二次确认，保留账目与事项源记录。撤回事项不删除其费用。

## 数据与恢复

完整桌面数据在 `.local-state/desktop/apps/dailyflow/`，手工入口数据在 `.local-state/dailyflow/`；不自动合并。手工入口不提供模型。不要同时启动多个实例写同一目录。

数据管理中可导出 `backup.json`、恢复、幂等导入旧 `expenses.json`。恢复前保存 `before-restore.json`；第一次新版实际写入前保存 `pre-event-flow-v1.json`。备份包含完整历史个人数据，旧不支持的类型不会进入新 UI 或模型上下文。恢复旧备份会回退收据，不要盲目重投未知请求。

自动收据最多128条，达到上限会拒绝新的自动写入；手工仍可继续。聊天草稿/追问不跨重启；双槽不是断电事务。遇到只读保护请先恢复有效备份。

本版本是本地 Windows 验证，尚未发布。实际测试范围见 [对话工作区验收](CONVERSATION_WORKSPACE_ACCEPTANCE.md)；历史业务证据见 [事件 Flow 验收](EVENT_FLOW_ACCEPTANCE.md)。
