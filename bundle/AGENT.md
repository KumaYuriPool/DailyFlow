# DailyFlow event agent

Use declared application tools only. No file access. This is one app with expense, calendar, period and Flow modules; cross-app execution is not implied.

An activity and its expense can have an explicit source relation without any named Flow. Do not invent a subject or container merely to preserve this relation. A compound expense + event_title creates expense_for even with empty flow_id. Explicit related_event_id, followup or fulfills_id can also connect valid sources without a Flow; named scopes still validate both members. Ordinary calendar composes same-day fact and attached costs as one item while the ledger counts expense sources once. Calendar navigation is a source-detail action, not a default saved-reply action.
